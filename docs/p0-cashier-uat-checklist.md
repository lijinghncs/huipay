# P0 基础收银闭环 · UAT 验收清单

> 配套迭代计划：[p0-cashier-closed-loop-iteration.md](./p0-cashier-closed-loop-iteration.md)
> 用途：上线前按此清单逐项验收「商户管理 → 微信支付参数配置 → 商户收款码 → 消费者扫码付款 → 交易结果查询」全链路。

## 前置条件

- [ ] 微信支付商户号（平台级 + 至少 1 个测试商户）已配置，10 个 `HUIPAY_WECHAT_*` 参数齐全。
- [ ] 公网回调域名已 ICP 备案，并在微信商户平台配置支付回调域名。
- [ ] 商户微信配置敏感字段已由管理端录入（`PUT /v1/admin/merchants/:id/wechat-config`），DB 中为 AES 密文。
- [ ] `HUIPAY_WECHAT_CFG_ENC_KEY` 已设置（生产 fail-closed）。
- [ ] 数据库迁移 0001–0013 已执行。

## 1. 商户管理

- [ ] 管理端进件商户：名称/法人/证件/银行卡/联系人必填校验生效，`entity_code` 唯一且自动生成。
- [ ] 进件后商户自动开通钱包（`wallet_no` 生成、余额 0）。
- [ ] 商户列表分页/关键词/状态筛选正确；详情展示资料 + 钱包余额 + 微信配置状态。
- [ ] 编辑资料与启用/停用生效；停用后该商户码牌扫码不可建单。
- [ ] 商户端「概览」页展示商户资料、余额、累计实付、订单数、可用收款码数。

## 2. 微信支付参数配置

- [ ] 管理端录入/更新微信配置：enabled、mchid、appid、证书序列号、notify_base_url、4 个敏感字段。
- [ ] 校验：enabled=true 时 mchid 必填；私钥/平台公钥非法时拒绝保存。
- [ ] 敏感字段只回 `*_configured` 布尔，任何接口不回显明文。
- [ ] 编辑留空敏感字段不覆盖原值（DB 密文不变）。
- [ ] **配置生效**：商户配置微信后，下单 `notify_url` 为 `/v1/notify/wechat/{merchant_id}`；未配置商户仍走平台 `/v1/notify/wechat`。

## 3. 商户收款码

- [ ] 商户端「收款码」页：创建（备注）、列表（短码/备注/状态/时间）、停用。
- [ ] 短码 6 位且不含易混淆字符（0/O/1/I/L），重复冲突自动换号。
- [ ] 查看二维码（antd QRCode）、下载 PNG、复制收款链接均可用。
- [ ] 停用后二维码扫码进入金额页提示"该收款码不存在或已停用"。

## 4. 消费者扫码付款

- [ ] 扫描二维码进入 `h5?code={code_id}`，展示金额输入页。
- [ ] 金额范围校验：0.01–50000.00 元，越界给出提示；非法输入被拒。
- [ ] 微信内默认拉起 JSAPI；非微信内默认 H5；NATIVE 选择后展示二维码并可轮询成功。
- [ ] 支付成功进入结果页（金额/订单号/支付时间）；支付失败展示原因并可重试。
- [ ] 订单 15 分钟超时：倒计时展示，超时后自动关单并提示重新建单。
- [ ] 回调延迟场景：通道侧已支付时收银台显示"支付处理中"，不重复支付、不重复建单。

## 5. 交易结果查询

- [ ] 商户端交易列表：状态/通道/码牌/时间筛选、分页、本页金额/实付合计。
- [ ] 订单详情抽屉：订单号/商户单号/来源码牌/金额/实付/通道/渠道交易号/支付时间。
- [ ] 「查询通道状态」只读返回通道侧结果；本地以回调为准。
- [ ] 钱包流水 `biz_id`（PAYMENT）点击跳转订单详情；订单详情可查看对应流水（互为入口）。
- [ ] 回调幂等：微信重复回调不重复入账（钱包流水仅 2 条复式记录）。

## 6. 异常与安全

- [ ] 短码枚举失败（not_found/disabled/金额越界）在 `/metrics` 有 `payment_code_invalid_attempts_total` 计数。
- [ ] 金额篡改：回调实付金额与订单金额不一致时拒绝入账并告警。
- [ ] 生产环境已关闭 `X-Merchant-Id` 明文头信任（改走登录态 Bearer token）。
- [ ] 日志：trace_id 贯穿，错误日志带 `retry=yes/no` 便于排查。

## 7. 回归

- [ ] `go build ./...` / `go test ./...` / `go vet ./...` 全绿。
- [ ] merchant-portal / admin-portal / checkout-sdk 三端 `vite build` 通过。
- [ ] 未配置微信的存量商户支付行为与升级前一致（回退平台通道）。
